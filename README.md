# Iris Data Analysis Dashboard – Power BI

## Project Overview
This project presents an interactive Power BI dashboard for analyzing the Iris flower dataset. It helps users explore flower measurements and compare different Iris species through visualizations.

## Tools Used
- Microsoft Power BI
- Iris Dataset (CSV)

## Dashboard Features
- **Total Flowers:** Displays the total number of flower records.
- **Total Species:** Shows the number of Iris species.
- **Average Sepal Length:** Displays the average sepal length.
- **Species-wise Flower Count:** Compares the number of flowers in each species.
- **Scatter Plot:** Visualizes the relationship between petal length and petal width.
- **Interactive Slicer:** Filters dashboard visuals by species.

## Key Insights
- The dataset contains 150 flower records.
- It includes 3 Iris species.
- The average sepal length is approximately 5.84 cm.
- The scatter plot helps compare petal measurements across species.

## Files Included
- `Iris_Dashboard.pbix` – Power BI dashboard file.
- `dashboard-screenshot.png` – Dashboard preview (if uploaded).

## How to Use
1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Use the species slicer to explore and filter the dashboard.

## Project Objective
To practice data visualization and interactive dashboard development using Power BI.
